# Functional UX Traceability

Updated: 2026-06-27

This matrix tracks production-facing user capabilities, not isolated helpers.
Statuses reflect the current code state after the REC-PROGRAM-04,
REC-NEXT-MEAL-05, plan-completion, and Mini App continuity work.

## Status Legend

- `IMPLEMENTED`: wired through a user entry point, handler/route, service/domain logic, persistence, user display, and regression or acceptance coverage.
- `PARTIAL`: a production path exists, but at least one required surface, context, validation, or test is incomplete.
- `MISSING`: no production path found.
- `BROKEN`: a production path exists but has a known runtime or correctness failure.

## Open Product Gaps

1. Mini App meal editing is still read-oriented; Telegram owns the full correction and undo UX.
2. Mini App live workout execution is not yet equivalent to Telegram.
3. `NutritionContext` is now wired for the morning menu, evening nutrition summary, and AI meal reanalysis fallback; future recipe-only flows should use the same structured request layer when added.
4. Proactive delivery is Telegram-only; Mini App reflects the same state after opening but does not receive push notifications.

## Recent Fixes Captured

- `planv2:complete_missing` now remains in the plan-completion flow after each answer and returns to the smart plan hub only when complete or when the user navigates back.
- `menu:smartplan` now clears the plan-completion flow without raising `NameError`.
- Mini App next-meal workout clarification now writes the same daily flag as Telegram and refreshes from the same recommendation service.
- Mini App now displays today's meals from `/mini/api/meals/today`, so Telegram-logged meals are visible without recalculation in JavaScript.
- Next-meal recommendations now read the fasting daily flag; active fasting changes the budget, while "not fasting" returns to the normal path.
- Morning menu, evening nutrition summary, and AI meal reanalysis fallback now receive a structured `NutritionContext` that separates reported meals from planned meals and carries daily flags, restrictions, workout context, and tracking quality into the AI request.
- Dietary restriction classification event logging is restored across all classification branches.
