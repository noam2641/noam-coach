# מפת דרך מוצרית

## 2.0 RC אישי — החבילה הנוכחית

- Conversation Router מרכזי ו־state ב־DB.
- restart recovery, microflows, expiry ו־versioned callbacks.
- פרופיל, readiness, מקור וביטחון לכל נתון.
- יעד יחיד עם גרסאות.
- שלוש חלופות תזונה ושלוש חלופות אימון.
- Constraint Engine, Fit Score ותוכנית שבועית מאוחדת.
- דיווח אוכל, locked quantities, עריכה, Undo וזיהוי כפילויות.
- אימון חי, warm-up, quick workout, readiness, fatigue ו־deload.
- Health ZIP/XML תקופתי בהעלאה או מנתיב מקומי, Mini App, גיבוי, פרטיות ובדיקות.
- Event Log, Replay ו־offline evaluation harness.

## בטא אישית מבוקרת

- שבועיים של שימוש רציף עם DB מגובה.
- הרחבת evaluations מתמונות, ארוחות ותרחישי שיחה אמיתיים.
- מדידת זמן, חיכוך, ביטולים ו־flows תקועים.
- שימוש בייבוא תקופתי; HealthKit שוטף נדחה ואינו חלק מהשלב הנוכחי.
- בדיקת Mini App בטלפון דרך Tunnel.
- כיול יעדים לפי שלמות דיווח ומגמת משקל.
- פיצול נוסף של `coach_bot.py` והגדלת כיסוי end-to-end.

## בטא לחברים

- PostgreSQL.
- users/devices/tokens נפרדים.
- pairing והזמנות.
- העלאת ZIP דרך Mini App או אחסון קבצים מאובטח לכל משתמש.
- הרשאות, export/delete עצמי והסכמה מדעת.
- queue לעיבוד תמונות וקבצים.
- object storage מוצפן.
- dashboard admin, quotas וניטור עלות AI.
- feature flags ו־staging נפרד.

## מאמן חכם מתקדם

- יעד קלורי דינמי לפי מגמת משקל ושלמות דיווח.
- Meal Fingerprint ומנות חוזרות מותאמות למשתמש.
- קשר בין אוכל לפני אימון לביצועים.
- התאמת תוכנית לפי adherence אמיתי ולא רק יעד מוצהר.
- ספריית תרגילים רחבה ומיפוי מגבלות מקצועי.
- heatmap של נפח, plateau, deload והתאוששות.
- Experiment Mode וסיכום שבועי עם שינוי אחד לאישור.
- “מה עבד לי?” על בסיס נתוני אורך.

## מוצר מסחרי

- מנויים וסליקה.
- support tooling ו־human escalation.
- penetration test ו־privacy review.
- audit access ומדיניות retention.
- SLA, ניטור, backups ו־disaster recovery.
- חיבור ברקוד/מסעדות/מחירים באמצעות ספקים מורשים.
- אפשרות למאמן מוסמך לאשר או לשנות המלצות.
