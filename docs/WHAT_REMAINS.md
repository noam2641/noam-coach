# מה עדיין דורש רכיב חיצוני

כל עבודת הקוד המקומית שהוגדרה לבנייה מחדש הושלמה ונבדקה. הרשימה הבאה אינה backlog של Refactor; אלה משאבים או בדיקות שאי אפשר להשלים מתוך חבילת הקוד בלבד.

## Credentials ושירותים

- Telegram production token וזהות בוט אמיתית.
- OpenAI API key פעיל ובדיקות עלות/rate-limit מול השירות האמיתי.
- Google Calendar OAuth והסכמת משתמש.
- חשבון Sentry או מערכת ניטור חיצונית.
- ספק ברקודים, מחירי מוצרים או תפריטי מסעדות.

## Apple Health

- אין צורך ב־HealthKit או אפליקציית iPhone/Watch בשלב הנוכחי.
- הייבוא נעשה תקופתית מקובץ ZIP/XML, בהעלאה או מנתיב מקומי כשהבוט רץ על אותו מחשב.

## תשתית production

- HTTPS ציבורי עבור Mini App. לפיתוח אפשר Tunnel זמני; כתובת קבועה דורשת Named Tunnel/דומיין או שרת.
- שרת production, גיבויים, secrets manager וניטור.
- בדיקת עומס אמיתית וריבוי משתמשים.
- לפני הרחבה משמעותית: PostgreSQL, queue, object storage מוצפן והפרדת tenants/devices.

## אימות מוצרי ומקצועי

- צבירת golden dataset אנונימי של תמונות אוכל ותיקוני משתמש אמיתיים.
- כיול הערכות מזון ובטיחות אימון עם אנשי מקצוע.
- בדיקות שימוש ממושכות על מכשיר אמיתי ותנאי רשת אמיתיים.
- מדיניות פרטיות, תנאי שימוש וסקירה משפטית לפני הפצה רחבה.

כל האינטגרציות הללו כוללות בקוד validation, mocks/fixtures, הודעות שגיאה ותיעוד setup במידה שניתן לבדוק מקומית.
