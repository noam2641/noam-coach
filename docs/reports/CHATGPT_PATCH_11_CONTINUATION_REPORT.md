## למה נוצר הפאץ׳
המשתמש דרש לא לעצור על hotfixים נקודתיים אלא להמשיך מול כל רשימת המשימות ולוודא חיבור אמיתי בקוד. PATCH-11 מטפל בפערי המשך שנמצאו אחרי PATCH-10.

## תיקונים שנוספו

### 1. TASK-07 — תיקון runtime אמיתי במנוע תוכניות אימון
ב־PATCH-10 נוספו מבני 4 ימים מקצועיים ב־`exercise_plans.py`, אבל `planning.py` קרא ל־`_strategy_split_override()` בלי שהפונקציה הייתה קיימת. זה היה פער runtime שלא נתפס ב־compileall.

נוסף עכשיו:
- `consistency` ל־4 ימים: `FB1/FB2/FB3/FB4`.
- `balanced` ל־4 ימים: `U1/L1/U2/L2`.
- `performance` ל־4 ימים: `A/B/C/F`.
- ולידציה שכל הקודים קיימים ב־`PLANS` ושאורך ה־split תואם את התדירות.

### 2. TASK-03 — שמירה על עד 4 פעולות גם אחרי תיקון טקסט חופשי
נמצא שבמסלול תיקון טקסט חופשי של המלצת “מה לאכול עכשיו”, הקוד השתמש ב־`next_meal_action_rows()` אבל הוסיף עוד שורת כפתורים `מצב היום / תפריט`. זה החזיר חלק מהעומס שהמשתמש ביקש להסיר.

תוקן:
- מסלול תיקון המלצה כבר לא מוסיף `menu:home` נוסף.
- נשארת רק סט הפעולות המרכזי של `next_meal_action_rows()`.

### 3. TASK-05/TASK-06 — טקסט חופשי להחלפת ארוחה בתפריט יומי
עד עכשיו כפתור “החלף ארוחה” אמר למשתמש לכתוב טקסט כמו “תחליף לי את ארוחת הבוקר לחלבון אחר”, אבל לא היה handler ייעודי שמחזיק את הבקשה לפני ה־router הכללי.

נוסף שירות חדש:
- `noam_coach/services/daily_menu_edit.py`

הוא מזהה בקשות כמו:
- “תחליף לי את ארוחת הבוקר לחלבון אחר”
- “תשנה את ארוחת הצהריים בלי אורז”
- “רענן ארוחת ערב קלה”

ומחזיר:
- הצעת החלפה ממוקדת.
- שימוש בפריטים שהמשתמש כבר אישר בעבר כשאפשר.
- הבהרה שההצעה לא נספרת כאכילה עד אישור.
- כפתורים ממוקדים: אשר שאכלתי / רענן תפריט / מה לאכול עכשיו / מצב היום.

### 4. בדיקות חוזה חדשות
נוסף:
- `tests/regression/test_patch11_remaining_contracts.py`

הבדיקה מוודאת:
- קיים split override מקצועי ל־4 ימים.
- תיקון טקסט של next meal לא מחזיר כפתורים מיותרים.
- עריכת תפריט יומי מחוברת לפני ה־router הכללי.
- כפתור “החלף ארוחה” כבר לא נשאר הודעת UX בלבד.

## אימות שבוצע בסביבה כאן
עבר:
```text
python -m compileall -q planning.py noam_coach/bot/meal_text.py noam_coach/services/daily_menu_edit.py tests/regression/test_patch11_remaining_contracts.py
python -m pytest -p no:cacheprovider -q tests/regression/test_patch11_remaining_contracts.py
```

לא הורץ full pytest כאן בגלל חוסרי תלויות runtime בסביבת ChatGPT. אצל המשתמש full pytest כבר עבד בסביבה המקומית ולכן יש להריץ אותו אחרי חילוץ.
